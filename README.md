# Odyssea — Agência de Viagens Exclusivas

> Site institucional de agência de viagens premium

## 📌 Sobre o Projeto

Site modelo de agência de viagens com foco em destinos exclusivos e experiências de alto padrão. Apresenta os principais roteiros, diferenciais do serviço e canal de contato para orçamentos personalizados.

## ✨ Funcionalidades

- Seção hero com chamada para ação
- Apresentação de destinos e pacotes exclusivos
- Cards de experiências de viagem
- Formulário de contato e orçamento
- Layout totalmente responsivo

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Descrição |
|------------|-----------|
| **HTML5** | Estrutura semântica e acessível da página |
| **CSS3** | Estilo visual, layout e responsividade |
| **JavaScript** | Interatividade, manipulação do DOM e lógica do cliente |

## 🚀 Como Executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/mariniltonquintanilha-hash/Agencia-de-Viajem.git
   ```
2. Abra o arquivo `index.html` no navegador.

## 📁 Estrutura do Projeto

```
├── index.html    → Página principal
├── style.css     → Estilos e responsividade
└── script.js     → Interatividade e lógica
```
